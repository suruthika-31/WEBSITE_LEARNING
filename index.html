1. What is HTML?

HTML is the standard markup language used to create webpages.

HTML stands for HyperText Markup Language. It defines the structure of a webpage.

2. What is an HTML tag?

HTML tags are used to define elements on a webpage.

Examples include heading, paragraph, image, link and table tags.

3. What is the use of the <a> tag?

The anchor tag is used to create hyperlinks.

The <a> tag connects one webpage to another webpage or resource.

4. What is the use of the <img> tag?

It is used to display images.

The img tag displays an image using the src attribute.

5. What is CSS?

CSS is used to style HTML webpages.

CSS stands for Cascading Style Sheets.

6. What is a CSS selector?

A selector identifies the HTML element to be styled.

Examples are element, class and ID selectors.

7. What is Flexbox?

Flexbox is a CSS layout system.

Flexbox helps arrange elements in rows or columns.

8. What is responsive design?

Responsive design makes websites work on different screen sizes.

Media queries and flexible layouts are commonly used for responsive design.

9. What is JavaScript?

JavaScript adds functionality and interaction to webpages.

JavaScript can change webpage content, handle events and perform calculations.

10. What is a variable?

A variable stores a value in a program.

JavaScript variables can be declared using let, const or var.
